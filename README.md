
# VA Pro Demo (React + Vite + Tailwind)

A clickable demo for a Philippine VA-focused productivity SaaS.

## Quick start

1. Install dependencies
   ```bash
   npm install
   ```

2. Start dev server
   ```bash
   npm run dev
   ```

3. Build for production
   ```bash
   npm run build
   npm run preview
   ```

## Notes
- Tailwind is preconfigured.
- Demo data is seeded in `src/components/VADemo.jsx`.
- Tabs live under `src/components/tabs`.
